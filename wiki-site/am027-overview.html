AM027 導讀：AIE-ML v2 的陣列、時脈、記憶體保護與三代比較

AMD 官方 AIE-ML v2 架構手冊的總覽章節：這本手冊和 XDNA 2 的關係、陣列組成、時脈目標、ECC，以及三代 AI Engine 的比較表。

本文區分公開來源、原始碼查核與工程推導。未在本機執行 compiler 或 NPU；可用型別、可編譯、可派送、無 fallback、效能達標是不同證據。
本頁導覽這本手冊和這台機器的關係陣列組成與四種記憶體時脈與設定介面頻寬記憶體錯誤保護與特權暫存器三代比較表手冊內部不一致的地方和 XDNA 2 的對照來源與延伸

這本手冊和這台機器的關係

本頁是 AMD 手冊 AM027（Versal AIE-ML v2，編譯器代號 AIE2PS）的中文摘要，rev 1.1，2026-11-12 讀取。XDNA 2 用的是 AIE2P，沒有公開的專屬架構手冊；本頁的數字除非在「和 XDNA 2 的對照」一節另外寫明，都不能直接當成 AIE2P 的規格。

手冊共 60 節、27 張圖，修訂紀錄列出 1.0（2025-05-30）、1.0.1、1.0.2 與 1.1（2025-10-23）四版；1.1 更新了 Performance、Tile Architecture、兩種 interconnect、Memory Module、Trace 與世代比較表。引言把 AIE-ML v2 定位為 AIE-ML 的第二代：每顆 tile 的運算量最多兩倍、新增原生資料型別、能效更好。三個世代名稱的對照表在 規格缺口。

本 Wiki 把手冊拆成五頁：本頁、Tile、處理器、Memory tile、介面、開機與觀測。

Tile 的本地資料記憶體 每顆 tile 64 KB 核心 load／store，或 tile DMA

時脈與設定介面頻寬

Performance：整個陣列（含 interface tile）是單一時脈域。–1 速度等級、VCC_AIE 0.725 V 的目標是 1 GHz。

PL 時脈 500 MHz 非同步，在 array interface 跨時脈域
NPI 時脈 300 MHz 非同步

Clocking Structure：每顆 interface tile 有一個欄時脈閘控暫存器，控制同一欄所有 memory tile 與 tile 的時脈（不影響 interface tile 自己）；整欄沒用到時關掉可以省電。

記憶體錯誤保護與特權暫存器

Memory Error Handling：

記憶體 保護方式
Tile 程式記憶體 16 KB 兩組 8-bit ECC，各涵蓋 64 bits；可更正 1-bit、偵測 2-bit
Tile 資料記憶體 bank 0–1 256-bit word 的每個 32-bit lane 各有 7-bit ECC
Tile 資料記憶體 bank 2–7 每個 32-bit 一個奇同位；出錯時 memory module 發出事件
Memory tile 512 KB 全部 bank 都是每 32-bit 一組 7-bit ECC，另有 ECC scrubbing
Control module 三塊 SRAM：程式 32 KB、資料 16 KB（32-bit 介面）、共享 32 KB（128-bit 介面），以 32-bit 為單位檢查 ECC

Privileged Register Access Control：tile、memory tile、interface tile 各有少數特權暫存器，只管制寫入；AXI4 的 AWPROT[1]=0 代表安全交易。

手冊內部不一致的地方

讀全文時看到下列前後不一致，手冊沒有說明哪一個才對，本 Wiki 照原文並列、不自行更正：

  • Memory tile 的 bank：正文寫 8 個 bank、各 64 KB；比較表寫「16 x 32B banks」。
  • Memory tile DMA 的位址維度：特性清單寫 4D，DMA 一節寫 5D（含 iteration-offset）。
  • Memory Tile Overview 的特性清單把「Six memory to stream (MM2S)」列了兩次，第二次的內容（解壓縮、out-of-order、Finish on TLAST）是 S2MM 的功能；Memory Tile Memory 的寫入介面也寫成來自鄰居的 MM2S。
  • 累加器：Accumulator Registers 說 512-bit 可看成 16 個 32-bit lane；Functional Overview 的累加模式寫 64 個 32-bit lane 或 32 個 64-bit lane（對應 2048-bit）。浮點資料路徑圖上寫「Accumulator Register A 9x 1024b」「Exponent Register E 12x 128b」，暫存器表則是 8 個 2048-bit 累加器、E 為 64 bits。
  • 核心的直接 stream 介面：Interfaces 寫一進一出各 32-bit；Functional Overview 寫 2×32-bit subordinate、1×32-bit manager。
  • Memory-mapped AXI4 位址表的 row 欄位，表頭寫 [22:18]，下一列寫 [24:20]（5 bits）。

和 XDNA 2 的對照

  • 相同（有 AIE2P 來源）：compute tile 64 KB 資料＋16 KB 程式、memory tile 512 KB、DMA 通道數 2+2／6+6／2+2，見 Tile 微架構 引用的 aie-rt AIE2P 表與 mlir-aie 模型。
  • 不同：XDNA 2 在 Ryzen AI 上沒有 PL、NoC、PMC；Linux 驅動文件 描述的是 4x8 陣列、一列 memory tile、由韌體管理的欄分區。AIE2P 的累加器是 5 個 2048-bit（AIE2P 暫存器），本手冊是 8 個。
  • 未核實：stream 寬度、load／store 每週期位元數、MX6／MX9／fp8 型別、control module 在 AIE2P 上是否存在。本機 NPU 的時脈在先前量測筆記裡約 1.8 GHz，和本手冊 –1 等級的 1 GHz 目標不是同一顆晶片的數字。
